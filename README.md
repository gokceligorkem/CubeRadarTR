# Cube Radar TR

Windows için Cube Radar TR indirme sayfası.

## İndir

[En güncel şifreli paketi indir](https://github.com/gokceligorkem/CubeRadarTR/releases/latest/download/CubeRadarTR.zip) · [Sürümler](https://github.com/gokceligorkem/CubeRadarTR/releases)

ZIP, AES-256 ile parola korumalıdır. Parolayı paketi paylaşan kişiden ayrıca al. Güncel 7-Zip veya WinRAR ile ZIP'in tamamını bir klasöre çıkar; Motion ve config klasörleri uygulamayla birlikte bulunmalıdır.

## Kullanım

- Windows 10/11 x64 ve Npcap gerekir.
- CubeRadarTR.exe dosyasını açıp radarı başlat.
- Canlı yön için Windows yönetici onayı istenir.
- Pet eşitlemesi için radar açıkken karakter seçimine dönüp yeniden gir.
- Kişisel tercihler her bilgisayarda yerel olarak tutulur.

## Paket ve lisans

Uygulama, karşılık gelen kaynak arşivi, GPL lisansı ve üçüncü taraf bildirimleri şifreli ZIP içindedir. Bu depo indirme bilgilerini barındırır. Cube Radar TR, dr89mh/aion2-cube-radar projesinin değiştirilmiş GPL-3.0 sürümüdür.

SHA256SUMS.txt ile indirilen ZIP'in bütünlüğü kontrol edilebilir. ZIP parolası arşivi açmayı sınırlar; çıkarılmış uygulamanın yeniden paylaşılmasını engellemez.
